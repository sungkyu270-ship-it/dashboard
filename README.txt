2027년 국방예산 프로그램별 재원 대시보드

실행: index.html을 Chrome 또는 Edge로 열면 됩니다. 설치나 인터넷 연결이 필요 없습니다.
index.html, style.css, app.js, data.js를 같은 폴더에 보관하세요.

기능: 부문·회계구분 연동 필터, 프로그램/구분 검색, 차트 8종, 연도별 구성비 전환,
상세 표 열 정렬, 필터 결과 CSV 다운로드, 모바일 반응형 화면.

데이터: 상위 폴더의 2027년_국방예산_프로그램별_재원.xlsx에서 추출한 32개 행.
엑셀 변경은 자동 반영되지 않습니다. data.js를 갱신해야 합니다.
차감 재원은 음수로 포함합니다. 도넛·트리맵은 양수 재원 기준입니다.
프로그램별 합계는 원문 총지출과 각각 1억 원 차이가 있으며, 엑셀 수치를 그대로 사용했습니다.
